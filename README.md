# ORIS Socket Chat

## Описание

Учебное задание по дисциплине ОРИС. Реализован многопользовательский чат на TCP-сокетах с использованием собственного бинарного протокола и многопоточности (`threading`).

## Формат сообщения

Каждое сообщение состоит из: 

- 4 байта — команда (`JOIN`, `TEXT`, `LIST`, `QUIT`, `ERR`);
- 4 байта — длина полезной нагрузки (`payload`);
- N байт — данные сообщения.

## Поддерживаемые команды

| Команда | Назначение |
|----------|------------|
| JOIN | подключение пользователя |
| TEXT | отправка сообщения |
| LIST | получение списка пользователей |
| QUIT | корректный выход |
| ERR | сообщение об ошибке |
